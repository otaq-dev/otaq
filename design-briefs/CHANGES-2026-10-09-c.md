## 1. "Preview" becomes "Run", for any kind of project (decision 0035)
Preview assumed every project is a website. Users also build backends, CLIs, libraries and mobile apps.
- **Rename everywhere:** "Preview" → **"Run"**, "Start preview" → **"Run"**, "dev command" → **"run command"**,
  "Preview running" → **"Running"**. Rename the frame "13 · Previews" to **"13 · Run & Shell"**.
- **Run tab** (replaces the Preview tab): Run / Stop, status, port (`:4019`), and the **live output log**. It must
  read well for a backend too. Add one sample with **BILL-4** (`dotnet run`, an API log, no Open button).
- **Open URL is optional:** the **Open** button appears **only if the project has an Open URL set** (SHOP:
  `http://localhost:$PORT`). BILL has none, so no Open button. Show both cases.
- **The first-run dialog** asks for the **run command** (Ask Claude still suggests one), with examples from several stacks:
  `pnpm dev`, `dotnet run`, `cargo run -- serve`, `python -m app`. Add an optional **Open URL** field to the dialog.
- **Card chip:** `▶ :4019` (running) instead of a globe icon, which implied a browser. The header counter becomes
  "running" with a ▶ icon. Its menu lists running processes across projects.
- **Settings → project:** "Run command" (with Ask Claude) and an optional "Open URL" field with the hint "Leave
  empty for backends, CLIs and libraries".

## 2. New Shell tab (decision 0035)
- A **plain terminal (not Claude)** in the ticket's worktree, with `$PORT` and the ticket's env set. Sample: the
  user runs `curl localhost:4004/invoices/42/pdf -o out.pdf` in BILL-4's worktree.
- Same terminal look and focus rules as the agent Terminal (every key goes to the shell while focused;
  ⌘⇧` / Ctrl+Shift+` leaves). The header strip shows "Shell · not the agent" so it can't be confused with Claude's terminal.
- It survives closing the window and closes when the ticket is Done.

## 3. Tabs: "Runs" becomes "History"
- To avoid a clash with **Run**, the session-history tab **Runs → History**.
- The panel tab order is now **Terminal · Diff · Run · Shell · Ticket · History** (no Investigation tab). In the narrow
  panel, use icon-only tabs with tooltips (see section 4).
