## 1. Remove the Changes Requested column (decision 0034)
- **Delete the column** from every board (light and dark, 1280, 1440 and 1920 widths). The board now has **9 columns**:
  Backlog, Investigate, Ready for Dev, Dev (Queued and Agent Working), Needs Input, Ready for Review, Approved, Done.
- **Send back is an action, not a place.** In the Diff tab and the panel action bar, Send back moves the ticket
  **straight back to Dev → Agent Working**, and the agent continues in the same session. If the optional agent
  limit is on and full, it goes to **Queued** instead.
- **New card marker:** "**Sent back · 3 comments · round 2**". Sample: **SHOP-27 "Search results paging"** is now in Dev →
  Agent Working with this marker (it was in Changes Requested).
- **Send-back confirmation dialog:** remove any wording about "moves to Changes Requested". It should say the ticket goes
  back to the agent in Dev, and list the children that will pause.
- **Stack storyboard, step 3 "Parent sent back":** SHOP-18 appears in **Dev** with the Sent back marker, not in a
  Changes Requested column. SHOP-20 still shows Paused.
- **Card variants page:** replace the "Changes Requested" variant with "Agent Working · Sent back".
- Remove "Changes Requested" from the status legend, column lists, drag-and-drop rules and keyboard map. Dragging is no
  longer a way to send back.

## 2. Closed tickets (decision 0033)
- The **Done** column now holds two kinds of finished tickets, each with its own label:
  - **"Merged"** (SHOP-17)
  - **"Closed · not merged"** (add one sample, for example SHOP-26 after Mark closed)
- **Mark closed** (on an Approved ticket with an open PR) **closes the ticket**, and it moves to Done as "Closed · not
  merged". Update the confirmation in **"05 · Ticket side panel → SHOP-26 · Approved, PR open"**. It must no longer
  say "moves the ticket back to Ready for Review".
- **Close ticket** is available on **any ticket in any state**: the panel's "…" menu and the card's right-click menu.
  The confirmation mentions that a running agent will be stopped first.
- **Reopen:** a closed ticket has a **Reopen** button (and can be dragged out of Done) to Backlog, Investigate or
  Ready for Dev. The branch is kept.
- **Children of a closed parent:**
  - A new card flag, **"parent SHOP-26 closed"**. The child can't be approved.
  - A new **inbox item** in the "Interrupted & conflicts" group, with the actions **Reopen parent** and
    **Remove dependency**.

## 3. Terminal keyboard focus
- While the **terminal has focus, every key goes to Claude Code, Esc included.** Claude Code uses Esc to stop
  the agent and to choose "No" in prompts, and Esc Esc to rewind. Remove "Esc leaves terminal" and "double Esc
  is sent to the CLI".
- **Leaving the terminal:** a dedicated shortcut (**⌘⇧`** on macOS, **Ctrl+Shift+`** on Windows and Linux), clicking
  outside the terminal, or the inbox shortcut. Update the hint bar under the terminal: "Typing goes to the agent ·
  ⌘⇧` leave terminal".
- **Windows and Linux:** while the terminal has focus, app shortcuts use **Ctrl+Shift+…** (Ctrl+letter belongs to the
  terminal, for example Ctrl+C or Ctrl+J). Show both forms in the keyboard map, for example **⌘J / Ctrl+Shift+J** for next
  inbox item.

## 4. "Working" counts
- The counts disagree today: the header says "3 agents working", the Dev section says "AGENT WORKING 4", and the
  all-clear screen says "5 agents are working". Make them consistent:
  - The header chip becomes **"3 running"**, meaning agents actively doing a turn across all projects. The tooltip
    says "agents running across all projects".
  - The Dev section headers stay as **card counts** ("AGENT WORKING 4").
  - The all-clear screen uses the same "running" number as the header.

## 5. Small copy and visual fixes
- **Approved card (SHOP-26):** the button **"Closed" → "Mark closed"**.
- **Board sample:** SHOP-20 must not show *Paused* while SHOP-18 is in Ready for Review. On the board, show SHOP-20 as
  **"Restacking onto SHOP-18"**. Paused stays in the stack storyboard and the card-variants page.
- **Inbox "Resume all":** it resumes **interrupted sessions only**. SHOP-28 ("start interrupted") keeps its own **Retry
  start** button and is not covered by Resume all. Update the confirmation copy.
- **Worktree paths:** name the folder by ticket key, for example `~/.crewboard/wt/shop-web/SHOP-18` and
  `~/.crewboard/wt/crewboard/CREW-1`. This applies to the Cleanup list, terminal header, panel header and recovery screens (0029).
- **Project rail:** show project keys (**SHOP**, **BILL**, **CREW**) instead of SW, BA, CB, if update A didn't already.

## 6. Already matches the design (no change, just confirming)
- **Inbox:** no auto-advance. After answering, the ticket stays open, and ⌘J moves to the next item (decision 0016).
- **Stacked PRs:** opening a PR on the parent **unblocks the child**, which can then Open PR targeting the parent's
  branch. A child's **Local merge** still needs the parent merged. Make sure the disabled-approve tooltip says this
  (decision 0015).
