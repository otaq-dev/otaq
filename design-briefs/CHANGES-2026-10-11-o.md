# Design update O: the About section and the Open-source licenses dialog (2026-10-11)

Decision 0071 adds an **About** section to global Settings and a dialog listing every open-source project Crewboard ships.
Brief 15 is updated. Nothing else changes.

## Prompt to paste into the pen.dev design agent
```text
Crewboard gets an About section in Settings and an "Open-source licenses" dialog (decision 0071). Design them in
crewboard.pen, frame group "15 · Settings", in Crewboard Light and Crewboard Dark, at 1440×900 and checked at 1280×800.
Reuse the existing Settings layout, rows, buttons, links and the Theme credits dialog (Settings → Appearance) as the
pattern: same dialog size, header, scrolling body, "Copy notices" button and Esc / Done. Don't change any other frame.

1. Settings → About (new, the last entry in the Global list, below Appearance and Tools). Top to bottom:
   - A header block: a 64 px square app-mark slot, then "Crewboard" and the tagline "The board where you run your crew
     of agents". THE LOGO DOESN'T EXIST YET: draw a plain placeholder (rounded square in the accent color with a neutral
     glyph) and label it "placeholder · logo not decided". Don't design a logo.
   - Version row: "Version 0.1.0 · build bed9c10" (the build hash in monospace) with a secondary button
     "Copy version info". Show its copied state ("Copied") as a variant. Copied text example:
     "Crewboard 0.1.0 (bed9c10) · macOS 26.0 · arm64".
   - License row: "© 2026 The Crewboard Authors · MIT License" with a link "View license".
   - Row "Open-source licenses": "Crewboard ships with 613 open-source Rust crates, fonts, icons and syntax
     definitions." with a button "View" that opens dialog 2.
   - Row "Theme credits": the same row and dialog as in Appearance (link them; don't redesign the dialog).
   - A small muted footnote: "Claude and Claude Code are trademarks of Anthropic. Crewboard is an independent project
     and isn't affiliated with or endorsed by Anthropic."
   No update check, no "Check for updates" button, no website / GitHub / social links, no donate button.

2. Dialog "Open-source licenses" (opened from About):
   - Subtitle: "These projects' licenses ask for their notices to ship with Crewboard. Copyright stays with their
     authors."
   - A filter field at the top: "Filter by name or license".
   - Section "Bundled with the app", one row each, with license and a source link icon:
       Geist and Geist Mono fonts · SIL Open Font License 1.1 · github.com/vercel/geist-font
       Lucide icons · ISC · github.com/lucide-icons/lucide
       Theme palettes (9 projects) · MIT · "See Theme credits" link
       Syntax definitions (Diff tab) · Sublime HQ Packages license · github.com/sublimehq/Packages
   - Section "Rust crates · 613": one foldable group per license, header = license name + count, folded by default:
       MIT License 542 · Apache License 2.0 33 · Unicode License v3 19 · BSD 3-Clause 8 · zlib 3 · CC0 1.0 2 ·
       Mozilla Public License 2.0 2 · BSD 2-Clause 1 · ISC 1 · MIT No Attribution 1 · bzip2 1.0.6 1
     An open group lists its crates as "name version" in monospace with a source-link icon per row, then a
     "Show license text" fold that reveals the full text in a monospace block. Example open group:
       Apache License 2.0 · 33 — gpui 0.2.2 (github.com/zed-industries/zed), alacritty_terminal 0.26.1-dev
       (github.com/alacritty/alacritty), … 
     Example of a second group: Mozilla Public License 2.0 · 2 — dwrote 0.11.5, option-ext 0.2.0, with the note
     "Source code: linked next to each crate."
   - Footer: "Copy all notices" (copies the whole text) and "Done". Esc closes.

States to draw:
   a. About, light and dark.
   b. About with "Copied" on Copy version info.
   c. View license: the MIT text (Copyright (c) 2026 The Crewboard Authors) in a small dialog, same pattern as the MIT fold in
      Theme credits.
   d. Licenses dialog: all groups folded (light and dark).
   e. Licenses dialog: the Apache group open, with "Show license text" expanded and the body scrolled.
   f. Licenses dialog: filter "tokio" → only the MIT group, open, showing the tokio crates; and a filter with no matches
      ("No crate or license matches "foo"" with a "Clear filter" link).
   g. Licenses dialog in a 1280×800 window: the body scrolls, the footer stays.

Annotate: where Copy version info's text comes from (the version, the build commit, OS and architecture), that the
list is built into the app (no network), and keyboard: Esc closes, ⌘F / Ctrl+F focuses the filter.

List anything unclear or contradictory under "Open questions" instead of designing it silently.
```
