# 0071. About screen and third-party notices

- **Status:** Accepted
- **Date:** 2026-10-11
- **Related:** 0021, 0028, 0054, 0057, 0069

## Context
Otaq is MIT (0054), and the app ships about 600 Rust crates plus fonts, icons, theme palettes and syntax definitions.
Most of their licenses (MIT, Apache-2.0, BSD, MPL-2.0 and others) allow this only if their notices ship **with the app**,
not only in the source repository. Only the themes had that (the Theme credits dialog, 0069). The app also had no place that
shows its version, its own license or who made it.

## Decision
**Third-party notices.** `THIRD-PARTY-LICENSES.md` at the repository root lists everything Otaq ships that someone
else made:
- a hand-written part: Geist fonts (OFL), Lucide icons (ISC), the theme palettes (MIT, details in Theme credits), and the
  syntax definitions `syntect` bundles (Sublime HQ's Packages license);
- the Rust crates in the shipped binaries for all six macOS, Windows and Linux targets (no build-only or test-only
  crates), grouped by license, each license text in full. Otaq's own crates are left out.

It is generated by `scripts/licenses.sh` with `cargo-about` (config in `scripts/licenses/`), offline, so the same lock file
always gives the same file. Whoever changes dependencies runs it and commits the result with that change;
`scripts/licenses.sh --check` reports a stale file. It is **not** part of `check.sh` (the VMs would need `cargo-about`).

**About screen.** A last **About** section in global Settings shows:
- the Otaq mark (a placeholder until the logo is decided), the name and the line "The board where you run your crew of
  agents" (0028);
- the version and the commit it was built from, with **Copy version info** (version, commit, OS and architecture) for bug
  reports;
- "© 2026 The Otaq Authors · MIT License", with **View license** (the MIT text);
- **Open-source licenses**: a dialog with the contents of `THIRD-PARTY-LICENSES.md`, built into the app; a filter, license
  groups that fold open, each crate's source link, and **Copy all notices**;
- **Theme credits**: the same dialog as in Appearance (0069);
- "Claude and Claude Code are trademarks of Anthropic. Otaq is an independent project and isn't affiliated with or
  endorsed by Anthropic."

The update switch, Check for updates and the update notice are part of this section (0073). No website or repository
links yet: there is no public repository (0025).

**When it's built:** with the release work, after M14; not in M14 (0075). On the Tauri UI the notices also list the npm
packages the app ships.

## Alternatives considered
- **Notices only in the repository:** most of these licenses ask for the notice to ship with the binary, and 0069 already
  chose a dialog for the themes for the same reason.
- **A macOS "About Otaq" menu item:** the app draws its own window chrome and has no menu bar; Settings works the same on
  all three platforms.
- **Generating the notices at build time (`build.rs`):** every build would need `cargo-about`; a committed file needs it only
  when dependencies change.

## Consequences
- The design comes first (design update O, `design-briefs/CHANGES-2026-10-11-o.md`), then a ticket builds the section and
  the dialog, embedding `THIRD-PARTY-LICENSES.md` in the app.
- The copyright line names "The Otaq Authors", not a person. The logo is still open; its slot is a placeholder until decided.
