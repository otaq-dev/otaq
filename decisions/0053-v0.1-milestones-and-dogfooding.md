# 0053. v0.1 milestones (M0–M11), and Crewboard builds itself once usable

- **Status:** Accepted. The dogfooding part is superseded by 0062 (v0.1 is built outside Crewboard).
- **Date:** 2026-10-09
- **Related:** 0013 (milestone list superseded), 0021, 0025, 0027, 0049, 0050
- **Supersedes:** the milestone list in 0013

## Context
0013's milestones still included full stacking and a Rust PR-provider layer, both changed by 0049 and 0050. The SDD and
the ticket-writing agent need a current order. The user doesn't mind the exact order, and wants to start using Crewboard
as soon as it is usable: first on **Crewboard's own development**, then on their other projects.

## Decision
v0.1 milestones, macOS only until M11 (0027):

| # | Milestone | Contents |
|---|---|---|
| M0 | Foundations | Cargo workspace (core, app, cli), the name constant (0028), SQLite schema and migrations, the local check script (0056) |
| M1 | Background service | `crewboard daemon`, user-locked socket (0027), the app starts and connects to it, build-ID check and the "Service update ready" banner (0022) |
| M2 | Board | GPUI window, projects and keys, tickets and epics, ticket editor, base branch (0051), dependencies with cycle check, badges, Stack list, drag rules, pins |
| M3 | Sessions | Worktrees, two ports, PTY with `claude` and the plugin, terminal view, `crewboard attach`, keystroke relay and the unsent-text rule (0048) |
| M4 | Agent signals | Plugin skills and hooks, agent CLI commands with the permission scope (0031), the orange family, background work, last signal (0042) |
| M5 | Scheduler | Queued, beads-style readiness (0049), optional limits (0016) |
| M6 | Review and Local merge | Diff tab and comments, Send back, Local merge (0038), changed since review (0043), Close/Reopen, Submit/Park (0052), Done cleanup |
| M7 | Attention and recovery | Inbox and hotkey, OS notifications, the focused-terminal rule, reconcile and Interrupted, Before the restart, Cleanup view |
| M8 | Usage | Tokens, plan meter, limit detection (0020) |
| M9 | Run, Shell, Project terminal | 0035, 0019 |
| M10 | PR flow | Workflow skills, the confirmation dialog, push, Mark merged/closed, PR rework (0050, 0041), agent-to-agent answering (0030) |
| M11 | Windows and Linux | ConPTY and named pipe, the checks in Windows and Linux VMs (0021, 0056) |

- **Out of v0.1:** stacking (0049), the graph view (0006), importers, the planner agent, and the public launch (packaging, 0021).
