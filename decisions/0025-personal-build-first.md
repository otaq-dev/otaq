# 0025. v0.1 is a personal build: no test-repo choice, no finish line

- **Status:** Accepted
- **Date:** 2026-10-09
- **Related:** 0013, 0014, 0021, 0024

## Context
The product owner proposed choosing a first test repo and a measurable "v0.1 works" bar (a week of use,
15+ tickets, a 3-ticket chain, and so on).

## Decision
- **No public release straight away and no proof of concept.** The author is the first and only user. v0.1 is
  a build that runs on the author's own computer and is used daily and improved over time.
- **No designated test repo.** The author uses it on whatever projects they're working on (multiple projects,
  0024).
- **No formal finish line.** The public launch is decided later.
